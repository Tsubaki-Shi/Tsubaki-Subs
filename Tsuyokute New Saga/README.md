# Tsuyokute New Saga 字幕

本仓库收录 TV 动画 **《Tsuyokute New Saga》（強くてニューサーガ）** 第 5–12 集的简体中文／日文双语 ASS 字幕。

本字幕由 **Tsubaki-Subs** 制作，包含日文转写校对、简体中文翻译、片头曲／片尾曲译文以及下集预告花字。字幕采用 ASS 格式，适配 1920×1080 视频，可直接作为外挂字幕使用。

## 当前内容

- 字幕范围：第 5–12 集
- 字幕语言：简体中文 + 日文
- 字幕格式：`.ass`
- 已完成日文转写校对，并同步修订相关中文译文
- 包含片头曲、片尾曲及下集预告的字体与样式
- 文件名与对应 Erai-raws 视频版本保持一致

当前收录：

```text
[Erai-raws] Tsuyokute New Saga - 05 ... .ass
[Erai-raws] Tsuyokute New Saga - 06 ... .ass
...
[Erai-raws] Tsuyokute New Saga - 12 ... .ass
```

## 关于第 1–4 集

第 1–4 集推荐使用 **「三明治摆烂组」** 的翻译。

本组开始制作本作字幕时，曾以为友组弃坑不会再补齐，后来对方已经完成。因此本项目当前主要收录第 5–12 集，前四集建议优先使用「三明治摆烂组」的版本。

## 使用方法

1. 下载与视频集数对应的 `.ass` 文件。
2. 将字幕文件与视频放在同一目录，并保持文件名主体一致。
3. 使用支持 ASS 字幕的播放器加载，例如 mpv、VLC 或 PotPlayer。
4. 为完整呈现样式，建议安装字幕中使用的字体。
