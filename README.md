# **Tsubaki-Subs** 字幕

本仓库收录由 **Tsubaki-Subs** 制作的 简体中文 或 日文双语 ASS 字幕。

## 使用方法

1. 下载与视频集数对应的 `.ass` 文件。
2. 将字幕文件与视频放在同一目录，并保持文件名主体一致。
3. 使用支持 ASS 字幕的播放器加载，例如 mpv、VLC 或 PotPlayer。
4. 为完整呈现样式，建议安装字幕中使用的字体。
